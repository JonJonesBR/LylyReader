# Segurança

## Reportando uma vulnerabilidade
Não abra uma issue pública para falhas de segurança. Use **Security → Report a vulnerability** (aviso privado do GitHub) neste repositório. Responderemos assim que possível.

## Chaves e dados
O app guarda chaves de API (por exemplo, a do Gemini) apenas no aparelho, em armazenamento criptografado. Nenhuma chave deve ser enviada ao repositório; o CI bloqueia padrões comuns de segredos.
